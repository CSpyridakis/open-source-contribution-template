# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

**Do not open a public issue.**

Report privately via GitHub's [Private Vulnerability Reporting](https://docs.github.com/code-security/security-advisories) or email **security@example.com**.

Expect an acknowledgement within 48 hours and a fix timeline after triage.
