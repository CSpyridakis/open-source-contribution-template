# Support

Need help? Use these channels — **not** the issue tracker (issues are for bugs and features).

- Questions: [GitHub Discussions](https://github.com/OWNER/REPO/discussions)
- Docs: link to docs
- Chat: link to Discord/Slack (if any)

Bugs and feature requests: open an [issue](https://github.com/OWNER/REPO/issues).
