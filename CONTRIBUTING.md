## Workflow

1. Fork and branch: `feat/short-name` or `fix/short-name`.
2. Make changes. Keep commits [Conventional](https://www.conventionalcommits.org/): `type(scope): summary`.
3. Run tests and lint before pushing.
4. Open a PR against `main`. Fill the PR template. Link the issue with `closes #N`.
